# YoungBell.github.io

Shaoduo Fu 的个人主页，使用 GitHub Pages 托管。

主页地址：<https://youngbell.github.io/>

## 修改内容

主页的内容与样式都集中在 [`index.md`](index.md) 中，不依赖 Node.js、数据库或后端服务。

## 发布设置

在仓库的 **Settings → Pages** 中选择：

- Source：**Deploy from a branch**
- Branch：**main**
- Folder：**/(root)**

保存后，GitHub 会自动生成并发布主页。
